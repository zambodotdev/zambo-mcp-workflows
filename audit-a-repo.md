# Audit a repo

## What it does

Runs a full AI-readiness audit of a GitHub repo or a website through Zambo: how discoverable it is to AI assistants, what is missing, and the fixes in priority order. The audit itself is Zambo tool work, so it comes with a receipt.

## Paste this prompt into any MCP client connected to https://zambo.dev/mcp

```
Use Zambo to audit this repo for AI discoverability and readiness: PASTE REPO OR SITE URL. Run the audit tools, then give me the findings as a short list of fixes in priority order, each with the reason it matters. End with the receipt link for the audit so I can check the work.
```

## What you get back

The findings list, the fixes ranked by impact, and a receipt link (zambo.dev/run/...) for the audit run. Open the receipt to see exactly what was checked and saved; anyone you share it with can check the same record.
