# Pay per call (x402)

## What it does

Runs a paid-tier Zambo tool with payment handled per call in USDC on Base through x402, inside a spend limit you set first. No subscription, no account top-up: the call quotes, you approve the spend, the work runs, and the receipt records it.

## Paste this prompt into any MCP client connected to https://zambo.dev/mcp

```
Use Zambo for this job: PASTE THE JOB. First check my spend limit status and tell me what this will cost. If it needs a paid call, pay per call with x402 inside my limit, never above it, then do the work and end with the receipt link.
```

## What you get back

The work, the amount actually spent, and a receipt link for the run. Humans can also buy a /bin/bash.99 Day Pass (24 hours) or a 9 Pass (30 days) instead of paying per call; agents pay per call in USDC on Base when an endpoint speaks x402.
