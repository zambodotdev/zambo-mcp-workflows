# Find leads

## What it does

Uses Zambo's lead tools to find people or companies matching a plain-language description of your customer, with the signals that make them worth contacting, and saves the run as a receipt.

## Paste this prompt into any MCP client connected to https://zambo.dev/mcp

```
Use Zambo's lead tools to find leads for this offer: PASTE WHAT YOU SELL AND WHO IT IS FOR. Return the best matches first, each with the evidence that makes them a fit and a one-line angle for reaching out. End with the receipt link for the search.
```

## What you get back

A ranked lead list with fit evidence per lead, plus a receipt link for the search run, so the list you act on is the list that was actually produced, checkable later.
